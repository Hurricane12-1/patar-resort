### Always-Active Quality Gates:
1. **Visual & UI Craft**: Avoid generic purple/indigo AI gradients and repetitive floating card grids. Use established brand design tokens (Rock View Beach Resort sapphire `#006699`, oceanic navy `#0b1120`, warm amber `#d97706`, seafoam emerald `#059669`).
2. **Accessible Contrast (WCAG 2.1 AA)**: All text pairings must meet at least 4.5:1 for normal text and 3.0:1 for large text. Verify new color pairings using the `antislop` MCP tool `check_contrast`.
3. **No AI Buzzwords in Copy**: Never use robotic filler words like `delve`, `tapestry`, `testament`, `seamlessly`, `elevate`, `cutting-edge`, `unleash`, `dive into`, `in conclusion`, `beacon`, `nestled`, `boasts`. Write clear, direct, and factual text grounded in Bolinao resort details.
4. **Code Quality**: Zero self-evident comments (e.g. `// increment counter`, `// return JSX`). Never silently swallow errors with empty catch blocks.
