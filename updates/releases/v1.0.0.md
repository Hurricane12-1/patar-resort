# Release v1.0.0 — Stable Baseline & Rebrand

**Release Date**: September 20, 2026  
**Platform**: J & D Beach House (Bolinao, Pangasinan)  
**Git Tag**: `v1.0.0-stable`

---

## Release Highlights

### 1. Brand Transformation to "J & D Beach House"
- Rebranded all customer-facing surfaces (Header, Hero Badge, Navigation bar, Footer, Chatbot, Customer Hub, and Staff Desks).
- Rebranded SMS transaction templates and notification headers.
- Standardized API endpoints, download filenames, and backup references.

### 2. Architecture & Modular Styles Separation
- Separated all embedded CSS styling into a dedicated TypeScript styles directory: `client/src/styles/modules/`.
- Created typed theme resolvers (`theme.ts`), admin dashboard styles (`admin.styles.ts`), chart wrappers (`charts.styles.ts`), and modal dialog definitions (`modals.styles.ts`).
- Standardized all component files to clean `.tsx` with zero `.jsx` dependencies.

### 3. Navbar Logo Spacing & Typography Fix
- Corrected line-height and vertical descender collision on the brand logo.
- Styled `J & D` with Cormorant Garamond serif and `BEACH HOUSE` with luminous sky blue sans-serif.

### 4. Security & Core Engine
- Next-Generation Web Application Firewall (NGWF) filtering SQLi, XSS, and path traversal payloads.
- Recursive Anti-XSS sanitizer for JSON request bodies and query parameters.
- Double-Submit CSRF cookie protection.
- GiST exclusion constraint preventing double-bookings at the PostgreSQL storage level.
- Multi-role role-based access control (Customer, Receptionist, Accountant, Administrator).
