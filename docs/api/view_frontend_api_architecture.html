🌐 HTTP / REST (Fetch API)

Used for synchronous, transactional queries and mutations.

  • Standardized JSON serialization and Content-Type negotiation.
  • Automatic injection of Bearer <JWT> token into every request.
  • Graceful HTTP 204 (No Content) resolution.
  • Network timeout handling and automatic fallback delegation.

⚡ WebSockets (Socket.io Client)

Used for bi-directional, real-time AI guest chat and operator interactions.

  • Located in client/src/lib/socket.ts.
  • Full duplex ws:// transport with automatic HTTP long-polling fallback.
  • Handshake authentication pass-through (auth: { token }).
  • Events: chat:message, bot:message, bot:typing.

🐘 Supabase BaaS Client

Used for direct database integration and change-data-capture channels.

  • Located in client/src/lib/supabaseClient.ts.
  • Encapsulates anonymous/authenticated Supabase credentials.
  • Direct Auth session listening and token refreshes.
  • PostgreSQL CDC Realtime Broadcast subscriptions for live updates.

⚡ Tri-Tier Handler Pipeline (UI Events ➔ Client Facade ➔ Express Routes)

The system decouples user interactions, network protocol dispatch, error recovery, and backend business logic into three distinct handler tiers, guaranteeing zero-crash resilience and clean separation of concerns.
